# AukOS e1000 驱动

e1000 驱动主体位于 `kernel/drivers/e1000/e1000.vix`，采用轮询式 RX/TX 描述符环。
Vix 负责复位、EEPROM MAC 回退读取、寄存器配置、环索引推进、收发超时与帧边界检查。

`kernel/drivers/e1000/e1000_shim.c` 只提供当前 Vix 无法直接表达的内核边界：

- PCI 设备发现与 BAR 准备；
- volatile MMIO/端口 I/O；
- 定宽 DMA 描述符与静态缓冲区访问；
- 内存屏障和初始化阶段的定时等待。

驱动优先使用 32 位 MMIO BAR，并保留 I/O BAR 回退。当前支持 Intel 设备号
`100e`、`100f`、`1010`、`107c` 和 `10d3`。网络栈通过统一的
`ethernet_*` API 选择 e1000 或原有 VirtIO 后端。

成功启动应包含以下串口日志：

```text
e1000: RX/TX descriptor rings initialized (polling)
ethernet: using Intel e1000 backend
net: gateway ARP entry learned
net: ICMP echo reply received from 10.0.2.2
```
